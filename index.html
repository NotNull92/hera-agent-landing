AI는 Unity를 추측합니다.
Hera Agent는 실측합니다.

LLM은 작년의 Unity API를 기억합니다. 당신은 매번 그 격차를 토큰과 시간으로 갚습니다.
Hera Agent는 AI에게 살아 있는 Editor를 직접 만지게 합니다 — 추측 대신 실측.

↓ Lite 무료로 시작 Pro로 재시도 줄이기 → 
// AI가 추측한 타입을 실제 어셈블리에서 검증 (Pro)
hera-agent-pro describe_type UnityEditor.EditorApplication

// 실행 전에 컴파일만 통과시켜 재시도 1회 절감 (Pro)
hera-agent-pro exec --check "return Camera.main.name;"

// AI가 Play Mode를 돌리고 콘솔 에러를 직접 회수
hera-agent editor play --wait && hera-agent console --type error
I · 마찰점

AI에게 Unity를 시키려면, 보통 이 모든 게 먼저입니다

그리고 그 모든 단계마다 시간이 새고 있습니다

Python 런타임

가상환경, 의존성 충돌, 버전 호환성 — 설치에만 하루. Unity 버전이 바뀌면 또 하루.

WebSocket 릴레이

상시 동작하는 서버 프로세스를 띄우고, 끊어질 때마다 재연결 로직을 손봐야 합니다.

JSON-RPC 설정

config 작성, 툴 등록, 클라이언트 재시작 — 새 프로젝트마다 처음부터 반복합니다.

Domain Reload 단절

스크립트 컴파일이 일어나면 연결이 끊깁니다. AI는 멈춘 자리에서 답을 기다립니다.

II · 해법

Hera Agent는 그 모든 단계를 없앱니다

설치하고, 명령하면, 실행됩니다. 그게 전부입니다.

01

하나의 바이너리

Go로 컴파일된 단일 실행 파일. 의존성 0개. 설치 30초.

02

직접 HTTP

localhost:8090으로 Unity와 직접 연결. 중간 서버 없음.

03

자동 연결

Unity Editor가 켜지면 Connector가 자동으로 시작됩니다. 설정 파일 없음.

04

Domain Reload 안전

스크립트 컴파일 후에도 파일시스템 기반으로 자동 복구됩니다. AI 작업이 멈추지 않습니다.

III · 기능

핵심 기능

AI에게 정확한 컨텍스트를 주고, 결과를 직접 회수합니다

Lite 무료로 시작하는 AI · Editor 통합 도구
Lite

exec — 런타임 C# 실행

AI가 작성한 C# 코드를 Unity Editor 안에서 즉시 실행합니다. 빌드 없이 결과값을 그대로 회수합니다.

hera-agent exec "return Camera.main.name;"
Lite

editor — Play Mode 제어

Play Mode 진입·종료·일시정지를 한 줄로. AI 에이전트가 직접 시나리오를 돌리고 결과를 확인합니다.

hera-agent editor play --wait
Lite

console — 로그 회수

Unity 콘솔 로그를 type별로 필터링해 stdout으로. AI가 에러를 직접 읽고 다음 수정 단계로 넘어갑니다.

hera-agent console --type error
Pro AI 코딩이 일상이 된 인디 개발자에게
Pro

exec --check — 실행 전 컴파일 검증

코드를 실행하지 않고 컴파일만 통과시킵니다. AI 에이전트의 "실행 → 실패 → 재시도" 루프를 한 번 건너뜁니다.

hera-agent-pro exec --check "return Camera.main.name;"
Pro

introspection — 라이브 API 탐색

실행 중인 어셈블리에서 타입·메서드·시그니처를 직접 회수합니다. AI가 LLM 학습 데이터가 아니라 지금 이 프로젝트에서 답을 가져옵니다.

hera-agent-pro describe_type UnityEditor.EditorApplication
Pro

batch — 다중 명령 일괄 실행

여러 명령을 JSON 한 파일로 묶어 한 번의 요청으로. CI/CD 파이프라인의 N번 HTTP 왕복이 1번이 됩니다.

hera-agent-pro batch --file deploy.json
IV · 작동 방식

작동 방식

복잡한 것을 숨기고, 단순한 인터페이스만 남깁니다

Terminal

hera-agent (Go binary)

→

HTTP POST

localhost:8090

Stateless · Auto-discovery · Domain-reload safe

실제 사용 예시

왼쪽은 명령, 오른쪽은 AI가 다음 단계로 쓰는 컨텍스트

// AI가 시작 전에 프로젝트 컨텍스트를 회수
hera-agent status
Connected: true | Project: MyGame | Unity: 6000.0.25f1

// AI가 Play Mode를 돌리고 에러를 직접 읽음
hera-agent editor play --wait && hera-agent console --type error

// AI가 씬의 모든 카메라 위치를 한 줄로 회수
hera-agent exec "return Camera.allCameras.Select(c => c.transform.position).ToList();"

// 커스텀 툴은 [UnityCliTool] 어트리뷰트만 붙이면 자동 인식
hera-agent spawn --x 0 --y 5 --z 0 --prefab Enemy_Boss

// AI가 성능 병목을 GUI 클릭 없이 한 줄로 추출
hera-agent profiler hierarchy --depth 3 --sort self

// Pro: AI가 실제 어셈블리에서 타입을 검증, LLM 추측을 교체
hera-agent-pro describe_type UnityEditor.EditorApplication

// Pro: 실행 전 컴파일만 통과시켜 재시도 1회 절감
hera-agent-pro exec --check "return Player.Instance.Velocity;"

// Pro: 빌드·테스트·검증을 한 요청으로 (CI/CD)
hera-agent-pro batch --file deploy-commands.json

VI · FAQ

자주 묻는 질문

Hera Agent는 Unity 6000.0 이상을 지원합니다.

아닙니다. Hera Agent는 Go로 작성된 단일 바이너리입니다. Unity 측도 UPM 패키지 하나로 설치가 끝납니다. 별도의 런타임이나 서버 프로세스가 필요 없습니다.

네. Domain Reload 시 HTTP 서버가 재시작되지만, 파일시스템 기반 heartbeat와 auto-discovery가 자동으로 새 포트를 찾습니다. 사용자는 아무것도 할 필요가 없습니다.

물론입니다. Hera Agent는 어떤 셸에서도 실행 가능한 CLI 도구입니다. MCP 클라이언트에 종속되지 않으며, Cursor, Claude Code, 또는 직접 작성한 스크립트에서 자유롭게 호출할 수 있습니다.

혼자 가끔 Editor를 자동화한다면 Lite로 충분합니다. AI 에이전트(Cursor·Claude Code·Copilot)에게 매일 Unity 코드를 시키고 있다면, exec --check로 컴파일 재시도를 줄이고 describe_type으로 LLM 추측을 실측으로 바꾸는 Pro의 가치가 빠르게 회수됩니다.

Pro 저장소는 비공개이며 Patreon 구독자에게만 GitHub Release 바이너리와 저장소 접근 권한이 열립니다. Unity Connector는 UPM git URL로 설치합니다. 최근 15일간 20개 릴리스가 나갈 만큼 활발하게 업데이트되며, Patreon 구독 동안 모든 신규 기능을 받습니다.

해지 시점에 받은 마지막 버전은 계속 사용할 수 있습니다. 다만 그 이후의 업데이트, 신규 Unity Pitfalls 카탈로그, 신기능, 우선 지원은 중단됩니다. 라이선스상 재배포·서브라이선스·경쟁 제품 개발은 금지됩니다.

C# 클래스에 [UnityCliTool] (Lite) 또는 [HeraAgentPro] (Pro) 어트리뷰트를 붙이면 자동으로 인식됩니다. Parameters 클래스로 인자 스키마를 정의하고, HandleCommand 메서드로 로직을 구현하세요. hera-agent list로 스키마를 확인할 수 있습니다.

다음 한 줄이 컴파일에서 죽지 않게

설치 5분, 첫 명령 1초. AI 에이전트의 다음 작업이 추측에서 실측으로 바뀝니다.
