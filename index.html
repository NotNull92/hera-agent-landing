설치하고, 명령하고, 실행됩니다. 그게 전부입니다.

01

하나의 바이너리

자동 연결

실제 사용 예시

// AI 에이전트가 Unity 연결 상태를 확인
hera-agent status
Connected: true | Project: MyGame | Unity: 6000.0.25f1

// AI 에이전트가 Play Mode 진입 후 콘솔 에러 확인
hera-agent editor play --wait && hera-agent console --type error

// AI 에이전트가 씬의 모든 카메라 위치 출력
hera-agent exec "return Camera.allCameras.Select(c => c.transform.position).ToList();"

// AI 에이전트가 커스텀 툴 호출 (자동 발견됨)
hera-agent spawn --x 0 --y 5 --z 0 --prefab Enemy_Boss

// AI 에이전트가 성능 프로파일링
hera-agent-pro profiler hierarchy --depth 3 --sort self

// AI 에이전트가 다중 명령 일괄 실행 (CI/CD)
hera-agent-pro batch --file deploy-commands.json

// AI 에이전트가 실행 중인 Unity API 라이브 탐색
hera-agent-pro describe_type UnityEditor.EditorApplication

자주 묻는 질문

Lite 버전은 Unity 2021.3 LTS 이상을 지원합니다. Pro 버전의 Connector는 Unity 6 (6000.0+)가 필요하며, Code Generation Target 기능으로 Unity 2021+와 Unity 6+ 각각에 최적화된 코드 힌트를 제공합니다.

아닙니다. Hera Agent는 Go로 작성된 단일 바이너리입니다. Unity 측도 UPM 패키지 하나로 설치 완료. 별도의 런타임이나 서버 프로세스가 필요 없습니다.

네. Domain Reload 시 HTTP 서버가 재시작되지만, 파일시스템 기반 heartbeat와 auto-discovery가 자동으로 새 포트를 찾습니다. 사용자는 아무것도 할 필요가 없습니다.

물론입니다. Hera Agent는 어떤 셸에서도 실행 가능한 CLI 도구입니다. MCP 클라이언트에 묶이지 않으며, Cursor, Claude Code, 또는 직접 작성한 스크립트에서 자유롭게 호출할 수 있습니다.

Patreon 구독자에게 GitHub Release 바이너리와 Private repo 접근 권한을 제공합니다. Unity Connector는 UPM git URL로 설치하며, Patreon 연동으로 Pro 기능이 자동 잠금해제됩니다.

C# 클래스에 [UnityCliTool] (free) 또는 [HeraAgentPro] (Pro) 어트리뷰트를 붙이면 자동으로 발견됩니다. Parameters 클래스로 인자 스키마를 정의하고, HandleCommand 메서드로 로직을 구현하세요. hera-agent list로 스키마를 확인할 수 있습니다.
